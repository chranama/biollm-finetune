# Documentation

This directory contains the active system documentation for BioLLM-Finetune.

- [Architecture](architecture.md): system shape, module boundaries, and data flow
- [Workflow Interface](interface.md): config, input, output, and validation contracts
- [Evaluation Method](evaluation.md): metrics, perturbations, and aggregation logic
- [Artifacts](artifacts.md): saved outputs and how to inspect them
- [Testing](testing.md): test categories, CI checks, and known boundaries
- [Runbook](runbook.md): setup, run, aggregate, validate, and inspect commands
- [Scope](scope.md): intended use, non-claims, and known limits
- [Research Notes](research/): deeper methodology and results writeups

Use the runbook for exact local command sequences. The other documents describe
system boundaries, interfaces, interpretation, and reviewable outputs.

Older planning notes are archived under `archive/docs/`.
