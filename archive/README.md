# Archive

This directory contains historical material that is not part of the active
repository documentation surface.

- `archive/docs/`: older planning notes that are no longer part of the active
  documentation set
- `archive/local_2024/`: earlier local experiment scripts and data snapshots
- `archive/server_2024/`: earlier server-side experiment scripts and data
  snapshots

The active system documentation lives in `docs/`. Research notes that are still
useful as deeper context live in `docs/research/`.
